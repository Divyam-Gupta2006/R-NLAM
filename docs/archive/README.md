and **predates independent verification**. The labels in these files
("IMPLEMENTED", "VERIFIED", "HARDENED", "PASSED") are claims, not evidence. Several are
contradicted by what the code does today; see [`../GAP_REPORT.md`](../GAP_REPORT.md).

They are kept for history only. Do not cite them to judges or reviewers. The current,
evidence-backed status lives in `docs/GAP_REPORT.md` and `PROGRESS.md`.
